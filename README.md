A console-based Railway Reservation System developed using Python and Object-Oriented Programming (OOP) concepts.

The application allows users to enter passenger details, view available trains, book train tickets, check seat availability, cancel tickets, and display ticket information.

Features

* Passenger registration and passenger detail management

* Display available trains

* Train seat availability checking

* Ticket booking

* Automatic fare calculation

* Ticket cancellation

* Seat availability update after booking and cancellation

* Ticket number generation

* Display booked ticket information

* Menu-driven console interface

OOP Concepts Used

* Classes and objects

* Constructors

* Instance attributes and methods

* Class attributes

* Object interaction

* Encapsulation

* Basic method-based data management

Classes
Passenger

Stores and manages passenger information such as:

* Passenger ID

* Name

* Age

* Gender

* Mobile number

Train

Stores train information such as:

* Train number

* Train name

* Source station

* Destination station

* Total seats

* Available seats

* Fare per ticket

Ticket

Handles:

* Ticket booking

* Ticket number generation

* Fare calculation

* Ticket cancellation

* Ticket status

* Ticket information display

Technologies

* Python 3

* Object-Oriented Programming

* Command-line interface
